颜色轮盘 · 100 XP

colors[x % 4] 中，% 4 的作用是什么？

除以 4 的余数只会是 0、1、2、3，所以颜色会不断轮换。
四色螺旋

把颜色轮盘放进循环

import turtle
t = turtle.Pen()
colors = ["red","yellow","blue","green"]

for x in range(100):
    t.pencolor(colors[x % 4])
    t.forward(x)
    t.left(91)

教材 2.5 · 一个变量搞定一切

sides 控制边数和颜色数量

import turtle
t = turtle.Pen()
turtle.bgcolor("black")
sides = 6
colors = ["red","yellow","blue","orange","green","purple"]

for x in range(360):
    t.pencolor(colors[x % sides])
    t.forward(x * 3 / sides + x)
    t.left(360 / sides + 1)
    t.width(x * sides / 200)
变量画廊

只改 sides，图形就会变身

sides = 6：六种颜色的旋涡
sides = 4：方形旋转感
sides = 3：三角风车
sides = 2：奇怪的蝴蝶线
